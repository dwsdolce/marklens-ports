Marklens

A fast, native Markdown viewer. Open a .md file to see it rendered, with syntax highlighting and Mermaid diagrams.

Opening & navigating

  • Open a file from File ▸ Open, or pass one on the command line.
  • Links to other documents open in the viewer; use View ▸ Back to return.
  • Links to a heading jump to it — both within the document (#installing) and into another one (setup.md#installing).
  • External links (http, mailto…) open in your web browser.
  • Images and links resolve relative to the document’s folder.
  • Back returns to where you were reading, not just to the previous document: following a heading link and then going back lands on the link, not at the top.
  • File ▸ Open Recent lists what you have read lately. All three Marklens ports share one list, so a document opened in one appears in the others.
  • The view reloads automatically when the file changes on disk.

Make Marklens the default for .md files

Double-clicking any Markdown file will then open it in Marklens. (Requires Marklens to be installed as an application.)
